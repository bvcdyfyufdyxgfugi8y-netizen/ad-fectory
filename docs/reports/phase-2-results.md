# نتائج المرحلة الثانية — استوديو الإنتاج المحلي

التاريخ: 2026-10-10. بيئة التحقق: Linux، Node 24.19، ffmpeg 7.1.5، Chromium محلي، Next.js 16.4.0.

## ما بُني

- واجهة عربية RTL متجاوبة: المشاريع، نموذج المنتج، حقائق المنتج والأسعار والجمهور والهوية.
- رفع صور المنتج والشعار، والتحقق من الصيغة والمحتوى والحجم ورفض SVG غير الآمن.
- اختيار واحدة من ثلاث افتتاحيات، وتحرير النصوص وترتيب المشاهد ومدتها بالإيقاعات والصور وتمييز الكلمات.
- معاينة من قالب Remotion نفسه. إطار المشغّل LTR لتصحيح الموضع؛ اتجاه النص داخل المشاهد حسب لغة الإعلان.
- حفظ البيانات والمشاهد في SQLite. التعديلات تلغي الاعتماد، والتصدير يتطلب اعتماد النسخة المحفوظة.
- مهام دائمة مع سجل إنتاج وتسليم منفصل لكل مهمة. العامل يعمل خارج خادم الواجهة.
- نسخ مستقلة من المدخلات عند إدخال المهمة في الطابور، لمنع تأثير تعديلات لاحقة على إنتاج جارٍ.
- النص اليدوي محفوظ في حقول `approvedCopy` من بيانات الإعلان. نص المنشور يتبع الافتتاحية والدعوة المعدّلتين.

## التحقق

- `npm run check`: TypeScript وlint و**30 اختبارًا مسمى** اجتازت بنجاح.
- `npm run build`: نسخة الإنتاج تُبنى بنجاح.
- اختبار المتصفح يغطي إدخال البيانات والرفع والتحرير والحفظ والاعتماد واستمرار البيانات بعد إعادة التحميل.
- يشمل التحقق رفض تعديل نسخة قديمة، ورفض طلب تعديل من أصل مختلف، ورفض SVG يحوي سكربت.
- أضيف تحقق من موضع صورة المعاينة داخل إطارها، بعد كشف خلل اتجاه RTL وتصحيحه.
- صور الواجهة: [الحاسوب](phase-2-desktop.png) و[الهاتف](phase-2-mobile.png).

`UI_RENDER_TEST=1 npm run test:ui`: **اختباران ناجحان**، يتضمنان تصديرًا حقيقيًا من الواجهة:

| التشغيل | الزمن المقاس | إعادة استخدام الصوت | إعادة استخدام الصورة | QC |
|---|---|---|---|---|
| أول إنتاج، 10 ثوانٍ | 382.8 ثانية | لا | لا | PASS |
| إعادة الإنتاج دون تعديل | 28.9 ثانية | نعم | نعم | PASS |
| تعديل الدعوة للإجراء ثم الإنتاج | 329.4 ثانية | نعم | لا | PASS |

تم تحميل التسليمات عبر API الواجهة وفحص الفيديو بـffprobe: **1080×1920، 30 fps، H.264 yuv420p،
AAC 48 kHz، 300 إطار، 10 ثوانٍ، −14 LUFS، true peak −1.3 dBFS**. نص المنشور المعدّل يحتوي
«اطلب اليوم» ويطابق المشهد. النسخة المحفوظة في `samples/phase-2/` هي التصدير المعدّل.

الأزمنة مقاسة أثناء تشغيل اختبارات وتصادرات أخرى بالتوازي في البيئة نفسها؛ لا تمثل أداء جهاز مخصص.
`npm run e2e`: **E2E PASS** في التشغيل النهائي: أول تصدير 759.4 ثانية أثناء المنافسة على الموارد،
إعادة تصدير محفوظة 16.3 ثانية، وتصدير بعد تعديل النص 272.6 ثانية. اجتاز QC في كل تشغيل؛ أعيدت
الصورة فقط بعد تعديل النص، ثم استُعيدت نسخة التسليم الأصلية. لم تمنع إضافة الواجهة أو تمييز الكلمات
أوامر CLI القديمة من العمل.

## نطاق النسخة

هذه أداة محلية لمستخدم واحد. لا توجد حسابات أو نشر عام أو خدمات سحابية أو تكاملات مدفوعة.
القالب الوحيد هو Bold Commercial؛ تغيير النبرة لا يبدّل الأسلوب البصري بعد.
المعاينة تعرض الحركة؛ ملف التصدير يضيف الموسيقى والمؤثرات. التعليق الصوتي وتزامن الكلمات في المرحلة الثالثة.
المخرج الإبداعي القائم على LLM اختياري ومؤجل؛ المخرج الحالي يعمل بالقواعد وتكلفة API صفر.
لم تُجرّب النسخة على Windows أو macOS. كشف منطقة الأمان آليًا غير موجود؛ الفحص التقني لا يثبت الجودة الإبداعية.

## المراجعة البصرية

صور الحاسوب والهاتف تُظهر النص العربي والمنتج والمعاينة داخل الإطار دون تمدد أفقي للصفحة.
فُحصت ورقة اللقطات والغلاف للتصدير الأصلي والمعدّل: الحروف العربية متصلة، والمنتج ظاهر في مشهدي
الظهور والدعوة للإجراء، والنص المعدّل ظاهر في الصورة. لا توجد مشكلة قص ظاهرة في اللقطات المفحوصة.
ملاءمة الموسيقى والأسلوب للعلامة لم تُحسم بالمراجعة الآلية.
مراجعة الإعلانات النهائية، ومنطقة الأمان، والتباين، ووضوح الدعوة للإجراء تحتاج قرار المالك؛ الاعتماد
والفحص التقني مساران مختلفان. لا تُعد النتيجة جاهزة لعميل حقيقي لمجرد اجتياز QC.
