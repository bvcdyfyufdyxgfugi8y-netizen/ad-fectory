# Two products, one engine

Both products are fictional, and all SVG artwork is original AD Factory code. Regenerate using:

```bash
npm run produce -- briefs/demo-nafas/brief.json
npm run produce -- briefs/demo-mint/brief.json
```

Nafas video is retained without duplication at `../engine-regression/after.mp4`; Nafas inputs and review
artifacts are in `nafas/`. Final MINT video/inputs/artifacts are in `mint/`. Original handoff is unchanged in
`../phase-1/`. The engine report is `../../docs/reports/phase-2-engine-results.md`.

No animation source is changed between these commands. MINT exercises alternate colors/type/transition,
product float, audio gains, export CRF and a structured planar camera preset.
