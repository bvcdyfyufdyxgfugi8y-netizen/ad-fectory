# عينة المرحلة الثانية

`demo-nafas-ui.mp4` إعلان تجريبي لعلامة خيالية، أُنتج من الواجهة ثم عُدّلت الدعوة للإجراء إلى «اطلب اليوم».
الملف اجتاز QC. الصور الأصلية والموسيقى والمؤثرات من المشروع، ولا توجد بيانات عميل حقيقي.

توجد هنا نسخة من brief والمشاهد والصور المستخدمة، والغلاف، ونص المنشور، وورقة اللقطات وتقرير الجودة.
`run.json` يحتفظ ببيانات المهمة الأصلية، ولذلك يشير إلى اسم ملف المهمة قبل نسخ الفيديو إلى هذا المجلد.

لإعادة إنتاج العينة:

```bash
npm run produce -- samples/phase-2/brief.json --storyboard samples/phase-2/storyboard.json
```

المخرجات تُكتب في `out/<brief-id>/delivery/`. مرجع المعاينة والتصدير هذا لا يغني عن مراجعة المالك الإبداعية.
