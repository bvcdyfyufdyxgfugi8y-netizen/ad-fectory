# Toon Studio palette reference

Preserves the owner's earlier requested color extraction from the Motion repository, pinned to commit `b6d3b6923b6bc9a8de1252ff0708d0da0ee26297`. The prior extraction was local only; the owner now requested integrating all work into main. `palettes.json` stores factual hex colors, source paths and provenance; exact duplicate Pop theme entries were removed. No source application code, fonts, audio or third-party images were imported. The source package is UNLICENSED; this is the owner-requested palette reference, not a licence claim or a dependency import.

Pop, Lilac and Onehero palettes remain design knowledge, not production defaults. New products use their supplied brand colors. This file does not implement or approve a Toon production template and does not change old advertisements.
